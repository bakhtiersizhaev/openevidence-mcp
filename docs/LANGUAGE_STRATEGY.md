# Language Strategy

This repository is English-first. Additional README translations should help real setup and discovery, not create a large duplicated documentation surface.

## Current Set

| Locale | File | Why it is included |
| --- | --- | --- |
| English | `README.md` | Canonical setup path for U.S., Canada, India, U.K., Australia, and most technical MCP users. |
| Russian | `README.ru.md` | Existing maintainer/user audience and strong technical search value. |
| Spanish | `README.es.md` | Broad healthcare and developer audience across Spain and Latin America. |
| Simplified Chinese | `README.zh-Hans.md` | Mainland Chinese technical and medical-AI search audience. |
| Traditional Chinese (Taiwan) | `README.zh-Hant-TW.md` | Taiwan has a distinct script, search behavior, and health-tech audience. |
| Korean | `README.ko.md` | Korea has active AI-in-health policy, regulation, and hospital modernization work. |
| Hindi | `README.hi.md` | India has a large healthcare/IT market; Hindi helps search and onboarding, while English remains primary for technical users. |

## Why No Separate Canadian English README

Canadian clinicians and health-IT users are best served by the canonical English README unless there is Canada-specific setup, compliance, or OpenEvidence availability guidance to maintain. A duplicate `README.en-CA.md` would likely drift and add little value.

## Market Signals Used

These are directional signals only, not claims of project adoption:

- The AMA reported in March 2026 that more than 80% of surveyed U.S. physicians used AI professionally, with medical research summaries among the top use cases: <https://www.ama-assn.org/practice-management/digital-health/more-80-physicians-use-ai-professionally-ama-survey>
- CIHI reported in April 2026 that almost all Canadian family doctors use electronic medical records and discussed AI/digital communication tools in family practice: <https://www.cihi.ca/en/understanding-family-doctors-well-being-insights-from-canada-and-international-peers/use-of-digital-communication-tools-and-ai-among-family-doctors>
- OECD's 2026 health-AI report tracks national strategies and workforce upskilling, including Korea and India policy signals: <https://www.oecd.org/en/publications/scaling-artificial-intelligence-in-health_a436e12d-en.html>
- Public 2026 reporting shows active AI-healthcare policy and commercialization discussion in China and Korea, but this repository should avoid claiming tested availability or local regulatory suitability without evidence.

## Translation Rules

- Keep translated READMEs short.
- Keep the English README canonical.
- Preserve unofficial, no-medical-advice, no-bypass, and user-session safety wording.
- Do not add adoption statistics, compliance claims, official-affiliation language, or medical claims unless they are verifiable and necessary.
