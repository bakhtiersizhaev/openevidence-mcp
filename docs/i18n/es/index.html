Resumen

OpenEvidence MCP es un servidor MCP no oficial que usa tu sesión de navegador. Permite validar auth, leer historial, obtener artículos por ID y ejecutar preguntas de investigación. No está afiliado a OpenEvidence, no ofrece consejo médico y no evita controles de acceso.

Qué es OpenEvidence

Este repositorio aporta un puente MCP no oficial para usuarios que ya tienen su propia cuenta de OpenEvidence.

Herramientas

  • oe_auth_status
  • oe_history_list
  • oe_article_get
  • oe_ask

Casos de uso comunes

  • Comparar literatura y revisar argumentos
  • Continuar preguntas de investigación con historial
  • Trabajar en Codex/Claude sin perder contexto
  • Usar OpenEvidence desde un workflow MCP propio
