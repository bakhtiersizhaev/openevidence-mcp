Overview

OpenEvidence MCP एक unofficial MCP server है जो browser session के ज़रिए OpenEvidence से जुड़ता है। इसमें auth check, history, article-by-id और ask-with-polling सपोर्ट है। यह OpenEvidence से affiliated नहीं है, medical advice नहीं देता, और access controls bypass नहीं करता।

OpenEvidence क्या है

यह repository उन users के लिए unofficial MCP bridge देती है जिनके पास अपना OpenEvidence account है।
