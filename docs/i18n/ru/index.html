Что это

OpenEvidence MCP — неофициальный MCP-сервер, который работает через вашу браузерную сессию OpenEvidence. Поддерживает проверку авторизации, историю, получение статьи по ID и запуск исследовательских запросов. Не связан с OpenEvidence, не является медицинской консультацией и не обходит контроль доступа.

Что такое OpenEvidence

Этот репозиторий даёт неофициальный MCP-мост для пользователей, у которых уже есть собственный аккаунт OpenEvidence.
