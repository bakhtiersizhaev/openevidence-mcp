概览

OpenEvidence MCP 是非官方 MCP 服务器，通过你的浏览器会话连接 OpenEvidence。 支持认证检查、历史列表、按 ID 获取文章，以及提问并轮询完成状态。 本项目不隶属于 OpenEvidence，不提供医疗建议，也不绕过访问控制。

什么是 OpenEvidence

这个仓库为已经拥有自己 OpenEvidence 账号的用户提供非官方 MCP 桥接层。
