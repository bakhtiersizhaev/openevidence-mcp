## Entry to add

- **[OpenEvidence MCP](https://github.com/bakhtiersizhaev/openevidence-mcp)** - Unofficial MCP server that connects OpenEvidence to Codex, Claude, Cursor, Cline, Continue, and other MCP-compatible clients through the user's authenticated browser session. Tools include auth status, history list, article fetch, and research questions with optional polling.

## Description for PR body

OpenEvidence MCP is an Apache-2.0 TypeScript MCP server that uses local Playwright browser-session auth. It is not affiliated with OpenEvidence, does not provide medical advice, and does not bypass authentication or access controls.
